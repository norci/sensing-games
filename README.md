# 体感游戏平台

基于单摄像头的浏览器体感游戏，无需手柄、无需穿戴设备，挥手即得。

---

## 设计原则

1. **模块化优先** — 核心逻辑（姿态检测、人体监控、摄像头管理）封装为独立模块，子游戏只写玩法
2. **性能优先** — 无人时自动降帧至 1fps，省 CPU；MediaPipe 模型选用 lite 版本
3. **避免误检** — 须检测到双肩或双髋方视为人体，单手臂不触发（见 `core/pose-utils.ts`）
4. **暂停防抖** — 无人後延迟 3 秒方暂停，避免短暂离开即中断游戏

---

## 目标

- 支持多种子游戏共用同一套姿态检测与人体监控基础设施
- 手机浏览器为主战场（iOS Safari / Android Chrome）
- 零安装，打开浏览器即玩

---

## 已支持游戏

### 水果忍者（`fruit-ninja`）

挥动单刀切水果，避开炸弹。

- 右手大幅度挥刀开始游戏
- 速度越快，火花特效越密集
- 支持连击（combo）计分
